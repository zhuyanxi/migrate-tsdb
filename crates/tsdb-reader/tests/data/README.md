# Vendored test fixtures

`block/` and `chunks.json` are a byte-for-byte copy of `fixtures/gen/data` from
the repository root. They are vendored so that `cargo test` still works from a
`cargo package` tarball, where `fixtures/` is not available.

Provenance: generated by `fixtures/gen` (`go run . -out data`) against the
vendored upstream Prometheus implementation. `block/ground_truth.json` is the
reference dump the tests compare against, so it must be regenerated together
with the block.

Refresh after regenerating the fixtures:

```bash
./scripts/dev-fixtures.sh          # regenerates fixtures/gen/data
./scripts/sync-fixtures.sh         # copies the small set into this directory
```

`tests/fixtures.rs` prefers this directory and falls back to
`../../fixtures/gen/data` when it is absent.
